# TaxiFare — Big Data & ML Pipeline

**Big Data · Machine Learning · Cloud-oriented Workflow**

## Overview
TaxiFare is a Le Wagon educational project that demonstrates how a machine-learning workflow changes when the dataset and execution environment become larger than a simple local notebook exercise.

## Portfolio focus
- larger-scale data handling;
- reproducible preprocessing;
- model training workflow;
- cloud-oriented data processing;
- model packaging / serving concepts;
- separation between experimentation and production-style workflow.

## Why it belongs in the portfolio
The project complements the business focus of Olist and the predictive focus of Graal by showing a more engineering-oriented side of data work.
