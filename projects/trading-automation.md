# Trading Automation

**Automation · Telegram · APIs · Risk Controls · AI-assisted Development**

## Overview
An automation system designed to read structured trading signals from Telegram, validate them, calculate position sizing and interact with the Bybit API.

## System workflow
`Telegram signal → parsing → validation → risk calculation → trade rules → Bybit API → logging`

## Key capabilities
- parsing symbols, direction, entry, stop-loss and take-profit levels;
- manual and automated operating modes;
- configurable risk controls;
- minimum-order and exposure guardrails;
- open-position checks;
- leverage and margin configuration;
- trade journaling and operational logs.
